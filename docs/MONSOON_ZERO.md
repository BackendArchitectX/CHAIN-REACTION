# MONSOON ZERO

A 420-second deterministic flagship scenario for CITY//01.

## Narrative

1. CITY//01 begins nominal.
2. Flood-like evidence appears near Substation 03.
3. Physical sensor and grid telemetry corroborate the incident.
4. Power degradation propagates into telecom, water, emergency response, and hospital dependencies.
5. Reality Forks compare no action, grid reroute, load shed, and reroute + mobile telecom.
6. The Resilience Envelope evaluates each plan across a shared set of plausible future parameters.
7. ROAD_12 can be blocked before the mobile unit arrives, invalidating the prior plan.
8. The forecast lease expires and Live Replanning is required.
9. A second telecom-load shock can be injected during recovery to expose recovery debt.
10. Audit/Replay exports a reproducibility capsule.

## Fixed seed

`271828`

Counterfactual branches use common randomness: the same sampled uncertainty is applied to every intervention so only the intervention changes between paired worlds.
