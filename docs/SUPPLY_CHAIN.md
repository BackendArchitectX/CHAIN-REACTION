# Software Supply-Chain Assurance

CHAIN//REACTION keeps the competition build reproducible without adding a cloud dependency to the runtime.

## Dependency contract

- Direct npm dependencies use exact versions.
- `package-lock.json` is committed.
- Local bootstrap and CI restore with `npm ci`.
- CI rejects high/critical dependency advisories.
- External GitHub Actions are pinned to immutable commit SHAs.
- CodeQL scans JavaScript/TypeScript on main and on a weekly schedule.

## Production evidence

A successful production verification emits:

- `dist/build-manifest.json` — SHA-256 digest and size for each production artifact.
- `dist/sbom.cdx.json` — CycloneDX software bill of materials generated by npm.

The production smoke gate recalculates artifact hashes and verifies the manifest before a build is considered valid. Consecutive production builds must also produce identical artifact manifests before verification succeeds.

## Build budgets

The current static application budgets are intentionally generous enough for the competition build while preventing accidental regressions:

- JavaScript: 1.5 MB uncompressed.
- CSS: 500 KB uncompressed.
- Total production files: 2.5 MB uncompressed.

Budget changes require an explicit repository change rather than silently accepting bundle growth.

## Runtime boundary

Generated supply-chain evidence describes the software artifact. It does not establish Snapdragon NPU execution. NPU claims remain controlled by the independent exact-device proof contract in `docs/HARDWARE_PROOF.md`.
