# Accessibility Contract

The operational state must remain understandable without relying only on color.

- State glyphs: `● Healthy`, `◐ Stressed`, `▲ Degraded`, `◆ Critical`, `× Failed`, `↻ Recovering`.
- Core navigation and controls use native buttons/inputs and remain keyboard reachable.
- The causal topology exposes an accessible text label.
- Reduced-motion preferences disable propagation animation.
- Audit/Event views provide a textual equivalent to graph changes.
- The UI is responsive and maintains readable hierarchy on narrower screens.

A finalist build should add a formal keyboard-only walkthrough and screen-reader check to the assurance evidence.
